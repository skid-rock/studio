# ADR-0003. Формат схемы параметров блока

- **Статус:** принято
- **Дата:** 2026-06-20
- **Контекст задачи:** STUDIO-005 (реестр блоков), Фаза 0 роадмапа.

## Контекст

Каждый блок в реестре описывает **параметры (props)**: типы, дефолты, ограничения.
Схема нужна как:

- источник дефолтных `props` при создании секции;
- основа для автопанели редактора (Фаза 1);
- контракт между документом и render.

В `wed` уже работает паттерн `ENVELOPE_SCHEMA` → `DEFAULT_STATE` → панель песочницы.
При обобщении на много блоков нужно выбрать формат схемы.

## Решение (Фаза 0)

Собственная **`ParamSchema`** — порт паттерна из `wed`:

- массив групп `{ group, items }`;
- элементы: `range` | `color` | `text` | `select` с полями `key`, `label`, `def`
  и типоспецифичными ограничениями (`min`/`max`/`step` для range, `options` для select);
- утилита `defaultsFromSchema(schema)` собирает дефолтные props.

Реализация: `src/render-core/schema.ts`.

## Обоснование

- **Проверено на envelope** — тот же паттерн уже даёт панель и дефолты в `wed`.
- **Минимально** — render-у достаточно дефолтов и типов; без JSON Schema-парсера
  и UI Schema-раскладки.
- **Расширяемо** — добавление `SelectParam` заложено под лейаут-архетипы Фазы 3.

## Пересмотр (Фаза 1+)

При автопанели редактора (Фаза 1) рассмотреть **JSON Schema + UI Schema** (JSONForms):

- валидация props при сохранении;
- условные поля (`x-condition`);
- переносимость схем между инструментами.

Если понадобится — отдельный ADR; миграция `ParamSchema` → JSON Schema может быть
механической (генерация или dual-write на переходный период).

**Решение Фазы 1 (STUDIO-012):** на MVP остаёмся на `ParamSchema`. Автопанель
строится из неё (`src/editor/fields-from-schema.ts`), ядро и слой панели изолированы
(перевод схемы в контролы — в одном модуле). Миграция на JSON Schema + UI Schema
(валидация, `x-condition`) — отдельной задачей при появлении нужды; благодаря
изоляции она будет локальной (генерация или dual-write на переходный период).

## Последствия

- Контролы/панель редактора **не входят** в Фазу 0 — только типы и `defaultsFromSchema`.
- Блоки (STUDIO-006+) описывают `schema` + `defaults` + `render` в едином модуле.
- Валидация props на уровне документа (Zod) и на уровне блока (схема) — разные слои;
  document schema (STUDIO-004) проверяет форму документа, `ParamSchema` — семантику блока.

## Отклонено сейчас

- **Сразу JSON Schema + UI Schema** — избыточно для Фазы 0; нет автопанели, нет
  внешних потребителей схемы; overhead JSONForms не окупается.
