# Мокапы UI собственного редактора (STUDIO-030)

**Статус: историческая спека** (STUDIO-030 выполнена; актуальный UI — живой
редактор `src/editor/`). Синхронизировать с кодом не обязательно. Файлы можно
использовать как песочницу для экспериментов над UI; в будущем мокапы могут
снова стать основой и точкой истины для интерфейса (см.
[дизайн-систему](../design-system.md)).

Спека интерфейса редактора без Puck — для реализации в STUDIO-032..034
(выполнено). Статические HTML-страницы: страница = состояние, без JS и
сборщиков. Уровень — wireframe+ (реальные токены/шрифты, без полировки
пикселей).

Мокапы пересобраны по [дизайн-системе](../design-system.md) (2026-07-04):
плавающие панели-карточки, глубина фоном-сценой (градиент + шум), крупные
скругления, фиксированный акцент хрома.

Задача: `gd-brain/tasks/studio/STUDIO-030` (карточка + implementation-plan).

## Как смотреть

Открыть html-файл в браузере (работает и по `file://`, и через
`npx serve` из корня репозитория). Токены подтягиваются из
`src/tokens/dist/cream-navy.css` — если его нет, сначала `npm run tokens`.

## Страницы

| Файл | Состояние |
| --- | --- |
| `screen-main.html` | Основной экран: секция RSVP выделена, панель с полями |
| `screen-empty.html` | Пустой документ: подсказка + «Добавить Hero», панель-заглушка |
| `screen-drag.html` | Drag секции: ghost «Наша история» + drop-индикатор |
| `screen-inline.html` | Inline-правка имён в Hero: каретка, пунктир, тултип |
| `screen-tokens.html` | Попап оверрайдов токенов поверх основного экрана |
| `components.html` | Витрина компонентов (виджеты полей, карточка, кнопки, обёртка) |

Скриншоты страниц — в `shots/` (имя = имя html-файла).

## Зоны экрана (1440×900)

Панели — плавающие карточки на фоне-сцене (градиент + шум), воздух между
панелями и краями окна — `--chrome-gap` (12):

```
┌ сцена: градиент + шум ────────────────────────────────────────────┐
│ ┌──────────────────── Шапка-карточка, 56 ───────────────────────┐ │
│ └────────────────────────────────────────────────────────────────┘ │
│ ┌ Палитра 240 ┐  страница лендинга прямо на сцене  ┌ Панель 320 ┐ │
│ └─────────────┘                                     └────────────┘ │
└────────────────────────────────────────────────────────────────────┘
```

- **Шапка**: имя документа · undo/redo · переключатель темы (3 пресета) ·
  «Токены…» · Загрузить/Сохранить · «Экспорт HTML» (primary).
- **Палитра**: 10 карточек блоков — подписи ровно из
  `src/sections/registry.default.ts` (поле `label`). Постоянная колонка
  (решение №2 дизайн-системы).
- **Холст**: страница лендинга шириной `container.max` (420) лежит прямо на
  сцене (скругление и тень — подача хрома); демо-секции Hero / Наша история /
  RSVP в теме cream-navy, тексты из `examples/landing.sample.json` и дефолтов схем.
- **Панель свойств**: заголовок = label блока; поля группами; 4 виджета
  по типам `ParamSchema` (text / select / color / range).

## Легенда «элемент → токен»

Хром редактора — токены `--chrome-*` из [дизайн-системы](../design-system.md)
(значения и роли — там, дубля здесь нет). Ключевое: акцент хрома фиксированный
(`--chrome-accent #1f2937`) — выделение секции, фокус полей, primary-кнопка,
слайдер, drop-индикатор; опасные действия — `--chrome-danger`; радиусы/тени/
отступы — `--chrome-radius-*`, `--chrome-shadow-*`, `--chrome-gap/pad`.

Токены темы (`src/tokens/dist/cream-navy.css`) остаются только у контента и
у свотча переключателя тем:

| Элемент UI | Токен |
| --- | --- |
| Шрифт всего UI редактора | `font.body` (Inter) |
| Ширина страницы в холсте | `container.max` |
| Фон страницы лендинга | `color.cream` (фон вехи — `color.cream-alt`) |
| Заголовки секций холста | `font.display` (Source Serif Pro) |
| Рукописный акцент в Hero | `font.script` (Florisel — реальный woff) |
| Вторичный текст секций | `color.text-muted` |
| Свотч переключателя темы | `color.navy` + `color.cream` (показывают тему) |
| Кнопка/иконка «Удалить» | `color.terracotta` (через `--chrome-danger`) |

## Что сознательно вне скоупа

- Мобильная раскладка редактора (десктоп-only).
- Интерактивность: состояния разведены по страницам, JS нет.
- Вложенность/контейнеры блоков (семя STUDIO-011).
- Секции холста свёрстаны «по мотивам» реальных модулей `src/sections/*`
  (упрощённо), а не через `renderDocument` — мокап, не рендер.
