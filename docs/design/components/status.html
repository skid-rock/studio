Статус и подсказки

Всё, чем интерфейс отвечает на действие: идёт, сколько, сколько штук, что дальше. Ни один из этих элементов не должен быть заметнее холста.

Спиннер — для «не знаем, сколько ждать», полоса — когда знаем. Обе крутилки замирают при prefers-reduced-motion.

Подменю

Подменю — тот же .ch-menu внутри .ch-menu__wrap: отдельного компонента для второго уровня нет. Раскрывается по hover, по .is-open и по фокусу внутри — клавиатура работает без скрипта.

Тултип со стрелкой

Дублировать секцию ⌘D Скрыть панель
Дублировать ⌘D← наведите: .ch-tip показывает подсказку без скрипта

Стрелка — модификатор стороны, а не отдельный элемент. Слои у всего этого — из шкалы --chrome-z-*: подсказка и тост живут выше попапа, попап выше затемнения.
