# Улучшения и дорожные карты

Папка для осознанно отложенной работы и планов её закрытия. В отличие от
[ADR](../adr/) (зафиксированные принятые решения — «почему так»), здесь то, что
ещё предстоит сделать.

## Что внутри

- **[backlog.md](backlog.md)** — технический бэклог: конкретные места в коде,
  работающие приемлемо сейчас, но требующие доработки. Формат `IMP-xxx`
  (где / симптом / корень / варианты / рекомендация / триггер).
- **[roadmap-control.md](roadmap-control.md)** — дорожная карта «Архитектурный
  контроль и ограждения»: как удерживать контроль над проектом в незнакомом
  фронтенд-стеке и не принимать предложения вслепую (`R1–R6`).
- **[roadmap-docs.md](roadmap-docs.md)** — дорожная карта документации сервиса и
  архитектуры: какие документы завести для онбординга и как контекст для ИИ
  (`D1–D8`).

## Соглашение

| Где | Что это | Состояние |
|---|---|---|
| [ADR](../adr/) | решение зафиксировано | сделано, точка во времени |
| [backlog.md](backlog.md) | известный долг в коде | ждёт триггера |
| `roadmap-*.md` | инициативы и их порядок | в работе по приоритету |

По мере выполнения пункты роадмапов переезжают в код, документацию или новый ADR.
