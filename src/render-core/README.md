# render-core

Ядро рендера и реестр блоков — агностичный к React, ванильный TypeScript.

## Назначение

- **Агностичный render.** Чистые render-функции на ванильном TypeScript, без
  зависимости от React. Один и тот же код рисует превью в редакторе и
  статический прод-артефакт (анти-drift, анти-bloat).
- **Документ-модель.** Типы `document.json`: `schemaVersion`, `theme`, `motion`,
  упорядоченное дерево секций (`{ id, type, props, children? }`); порядок —
  fractional index.
- **Реестр блоков.** Контракт «тип секции → `{ schema params, контролы, render }`».
  Первый модуль — `intro/envelope` (перенос из `wed`).

## Контракт (важно)

Код в `render-core/` **не импортирует React**. React только оборачивает этот
render в оболочке редактора (`editor/`, Фаза 1). Так прод-выход не тащит React.

См. роадмап (Фаза 0) и ADR в `docs/adr/`.
