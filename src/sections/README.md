# sections

Модули секций лендинга (курированный словарь блоков). **Пусто на Фазе 0.**

Каждая секция — модуль реестра вида `{ schema params, контролы, render }`,
зарегистрированный в `render-core`. Узкий словарь блоков вместо «универсального
холста» → чистый лёгкий выходной код.

Первые секции (Фаза 1, перенос из `wed`): `intro/envelope`, `hero`, наша
история, когда&где + карта, расписание, дресс-код, RSVP-форма, детали/FAQ,
обратный отсчёт.
