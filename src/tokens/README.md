# tokens

Токены темы. **Пусто на Фазе 0.**

- **Источник** — JSON по стандарту W3C DTCG (переносимый, совместим с Tokens
  Studio для Figma).
- **Генерация CSS** — через Style Dictionary.
- **Сид** — `tokens.css` из `wed` (переводим в DTCG).

Тема = курируемый набор токенов (палитра, типографика, отступы). Библиотека тем
и motion-пресеты — Фаза 3.
